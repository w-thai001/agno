### Cascade Patterns Discovered

#### 1. Sequential Cascades

**Pattern:** FSA₁ → FSA₂ → FSA₃ → ... → FSAₙ

**Examples Found:**
- Data Pipeline: Validator → Transformer → Serializer → Persister
- Auth Flow: Authenticator → Authorizer → Session Manager → Cookie Handler
- Workflow: Task Queue → Batch Processor → Stream Processor → Result Aggregator

#### 2. Parallel Cascades

**Pattern:** FSA₀ → {FSA₁ ∥ FSA₂ ∥ FSA₃} → FSA₄

**Examples Found:**
- Service Orchestrator: Load Balancer → {Service₁ ∥ Service₂ ∥ Service₃} → Aggregator
- Multi-format Parser: Input → {JSON Parser ∥ XML Parser ∥ CSV Parser} → Unified Output

#### 3. Conditional Cascades

**Pattern:** FSA₁ → Decision → {FSA₂ᴀ | FSA₂ʙ} → FSA₃

**Examples Found:**
- Circuit Breaker: Monitor → Decision → {Retry Handler | Fallback Strategy} → Response
- Error Recovery: Detector → Classifier → {Simple Retry | Complex Recovery} → Success

#### 4. Recursive Cascades

**Pattern:** FSA₁ → FSA₂ → ... → FSAₙ → FSA₁ (loop)

**Examples Found:**
- Workflow Engine: Initialize → Execute → Validate → {Continue → Execute | Complete}
- Rate Limiter: Check → {Allow | Delay → Check} → Process
